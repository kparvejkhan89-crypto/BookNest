Academic Assignment Demonstration

Design and Development of an Online Book Store Using Generative AI

BookNest is a complete, polished, frontend-only bookstore application built exclusively with semantic HTML5, modern CSS3, and Vanilla JavaScript. It illustrates how generative AI pair-programming elevates web design aesthetics, responsive accessibility, and client-side architecture without relying on external frameworks or backend databases.

Pure HTML5
CSS3 Flex & Grid
Vanilla JavaScript (ES6+)
LocalStorage Persistence
Zero Dependencies

Live Catalog & Filtering

Instantaneous search across book titles, authors, and genres combined with multi-criteria sorting (Price Low/High, Rating, Featured) and URL query syncing.

Persistent Shopping Cart

State synchronized across browser tabs using localStorage. Features quantity increments, dynamic subtotals, free shipping progress, and promo codes.

Fully Responsive Design

Fluid CSS grid and flexbox architectures meticulously tested across 320px mobile viewports up to 4K ultra-wide monitors with zero horizontal overflow.

Adaptive Light & Dark Theme

CSS custom variable design system switching cleanly between a warm cream bookstore aesthetic and a nocturnal slate/forest ambiance with storage memory.

Interactive Modals & Toasts

Custom Quick-View modal for in-depth book synopses and publication specs, plus a lightweight non-blocking floating notification toast system.

Simulated Checkout & Receipts

Safe client-side checkout simulation that validates customer information, calculates taxes, issues randomized order receipts, and resets state.

Methodology & Tooling

How Generative AI Shaped BookNest

Documenting the role of modern Generative AI in the iterative engineering of this assignment.

Architecture & HTML

Semantic HTML5 Generation

Generative AI was used to draft semantic HTML structures adhering to WAI-ARIA standards. Components like modal dialogs, accessible forms, breadcrumbs, and landmark sections were structured with screen-reader readiness and SEO best practices in mind.

UI & Aesthetics

CSS3 Architecture & Palette Harmonization

The AI assisted in generating a cohesive CSS design system utilizing CSS Custom Properties. The warm bookstore palette (#183B2B, #C47735, #FBFAF7, #F0E5D4) was mapped to both light and dark themes, while realistic 3D book spine gradients and card depth were engineered programmatically.

Logic & Interactivity

Vanilla JavaScript Algorithms

AI was prompted to generate reactive, modular JavaScript engines for the shopping cart (subtotal, threshold-based delivery calculation, coupon discounts, tab-synchronization via storage events) and catalog filtering (regex-based search, multi-field sorting, and URL query handling).

Quality Assurance

Responsive Testing & Edge Case Debugging

Generative AI helped audit edge cases such as empty cart states, invalid promo codes, zero search results, mobile drawer overflow bugs, and localStorage deserialization error trapping to ensure a rock-solid student submission.

Frequently Asked Questions

Everything You Need to Know

Common questions regarding the architecture, assignment constraints, and tech stack.

No. BookNest is an educational frontend project created for a college assignment titled "Design and Development of an Online Book Store Using Generative AI". All book listings, prices, promo codes, and checkout flows are simulated client-side. No physical goods are sold or shipped.
No server database (like MySQL, MongoDB, or Firebase) is used. The book catalog is stored as a structured JavaScript array in js/books.js, and shopping cart persistence is handled natively by the browser's localStorage API. This allows the site to function 100% offline and standalone.
BookNest strictly uses only HTML5, CSS3, and Vanilla JavaScript (ES6+). There are no frameworks (no React, Vue, or Angular), no runtime dependencies, no npm packages, and no backend servers. Simply opening index.html in any modern browser executes the entire site immediately.
Whenever you add, modify, or remove an item, the JavaScript Cart object serializes the state to a JSON string stored inside the browser's localStorage key booknest_cart. When you navigate between pages or reload, the cart is deserialized back into memory, preserving your items.
Generative AI served as an intelligent pair-programmer across all phases: brainstorming the bookstore aesthetic and palette, generating the clean HTML5 templates, structuring CSS custom properties and media queries, designing custom SVG cover art, writing JavaScript business logic for the cart and search filters, and validating cross-device responsiveness.
